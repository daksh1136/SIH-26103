# ProjectPulse 🚀

## SIH26103 — Integrated Project Monitoring Platform

ProjectPulse is an integrated project monitoring platform designed for the
SIH26103 problem statement by the Ministry of Statistics and Programme
Implementation (MoSPI).

The platform helps authorities monitor infrastructure and development
projects through centralized project data, milestone tracking, financial
monitoring, analytics, explainable risk scoring, and early-warning alerts.

## 🎯 Key Features

- 📊 Project monitoring dashboard
- 🏗️ Project progress tracking
- 💰 Budget and expenditure monitoring
- 📅 Milestone tracking
- 🚨 Project alerts
- 🤖 Explainable risk scoring
- ⚠️ Early-warning indicators
- 📈 Department-wise analytics
- 📋 Project updates and history
- 🔍 Project-level risk analysis

## 🧠 Risk & Early Warning Engine

ProjectPulse evaluates multiple project indicators:

- Physical vs financial progress gap
- Budget utilization
- Expenditure ratio
- Planned completion date
- Project delay
- Existing project status

The system produces:

- Risk score
- Risk level
- Risk indicators
- Risk reasons
- Recommended corrective action
